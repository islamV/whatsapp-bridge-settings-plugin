# Security Policy

## Supported Versions

The following versions of `whatsapp-bridge-settings-plugin` are currently supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within `whatsapp-bridge-settings-plugin`, please report it responsibly instead of opening a public issue.

### How to Report

- **Email**: Send details of the vulnerability to [islamabdelkarimpro@gmail.com](mailto:islamabdelkarimpro@gmail.com).
- **GitHub Security Advisories**: Submit a private vulnerability report directly via the GitHub repository's **Security** tab if enabled.

Please include the following information in your report:
- Type of issue (e.g. CSRF, XSS, unauthorized access, privilege escalation)
- Detailed step-by-step instructions or proof-of-concept to reproduce the issue
- Affected package version(s)
- Any potential remediations or patches if known

### Response & Handling Process

1. **Acknowledgement**: You will receive an initial response acknowledging your report within **48 hours**.
2. **Assessment**: The maintainer will investigate and verify the report within **5 business days**.
3. **Patch & Release**: Confirmed security vulnerabilities will be remediated and released in a patch update as quickly as possible.
4. **Disclosure**: A public advisory will be published along with the patch release, crediting the reporter if desired.

Thank you for helping keep `whatsapp-bridge-settings-plugin` secure!
